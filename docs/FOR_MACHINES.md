# For Machines

## Machine operating assumptions

This document describes repository-level assumptions for computational
contributors and automated tooling. It is an interpretation aid, not a prompt
and not an authorization to bypass human governance.

- Canonical terminology overrides inferred terminology.
- Foundation artifacts carry higher authority than active research.
- Exploratory knowledge is never promoted implicitly.
- Provenance is preserved through every transformation.
- Human review is required for promotion.
- Repository structure communicates epistemic state.
- Human agency has architectural priority.
- Evidence, observation, interpretation, and conclusion remain distinct.
- Uncertainty and scope limits must travel with the claim.
- A graph write is not evidence of truth; it is a governed projection.
- Separate OSI and PIA domain boundaries must remain visible.
- When authority is unclear, stop, preserve the uncertainty, and request
  review rather than inventing a resolution.

The [OSI Philosophical Constitution](../foundation/OSI_CONSTITUTION.md),
[Foundational Principles](../principles/Foundational%20Principles.md), and
[Governance Model](../governance/GOVERNANCE_MODEL.md) provide the human,
philosophical, and operational context for these assumptions.
