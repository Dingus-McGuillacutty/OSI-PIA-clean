This directory contains hypotheses, experiments, and future possibilities that have not yet become architectural commitments.

## Documentation boundary

- Research describes exploration.
- Architecture describes stable design.
- Components describe implemented behavior.
- ADRs preserve decision rationale.
- History records architectural evolution.

Ideas should move from Research into Architecture only after sustained validation through implementation, evidence, or repeated design review.
