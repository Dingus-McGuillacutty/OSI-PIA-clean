## Interpretation

Milestone status should be read together with artifact authority:

- `canonical/active` identifies a promoted authority;
- `working/proposed` identifies validated development that remains subject to
  review; and
- an operational gate may remain open after implementation tests pass.

This distinction is especially important for participant-data systems.
Technical completeness does not itself authorize real-participant processing.
