# Graph Evidence Visualizations

These diagrams are synthetic explanatory views of OSI/PIA relationships. They
are not screenshots of a live database and contain no participant data.

Two reusable formats are provided:

- `GRAPH_EVIDENCE_TOUR.md` — captions and Mermaid diagrams for documentation;
- `GRAPH_EVIDENCE_TOUR.mmd` — editable Mermaid source for later rendering.
- `LIVE_SANDBOX_GRAPH_TOUR.md` — five conceptual/implementation pairs grounded
  in the validated synthetic PIA and OSI sandbox projections;
- `LIVE_SANDBOX_GRAPH_TOUR.mmd` — editable Mermaid source for those
  implementation views.

The diagrams are arguments about traceability, bounded interpretation,
organizational conditions, and state change—not database dumps.

The live-sandbox tour is also a publication-safe evidence artifact. It uses
synthetic identifiers and exact validated relationship vocabulary while
excluding credentials, local paths, raw participant material, and connection
details.

The `images/` directory contains saved, publication-safe SVG views for the
five focal graph states used by the live tour. Mermaid remains the editable
conceptual source; these SVGs are the rendered visual evidence assets.
