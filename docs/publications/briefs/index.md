# Briefs and Project Updates

updates, and development explanations that do not need the form of a full
article. They are public supporting material: useful for orientation and
traceability, but not a substitute for canonical architecture, formal source
review, or governance decisions.

## Publication boundary

between established research, project interpretation, and open propositions.

organizational diagnosis, or consequential machine action.
