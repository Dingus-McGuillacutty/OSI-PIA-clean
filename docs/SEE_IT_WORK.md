# See It Work

This is a short proof path through the existing public demonstrations. It is
not a second documentation set.

All examples are synthetic or controlled. They show what OSI-PIA can represent
or distinguish in a bounded setting; they do not establish claims about real
people, organizations, or populations.

## Follow the proof path

1. Start with the [Graph Evidence Tour](evidence/visualizations/GRAPH_EVIDENCE_TOUR.md) to see how source-grounded evidence, bounded capability interpretation, and organizational conditions remain distinguishable.
2. Read one of the synthetic evidence cases:
   - [Capability Blockage](evidence/demonstrations/OSI_Evidence_Case_001_Capability_Blockage.md)
   - [False Capability Signal](evidence/demonstrations/OSI_Evidence_Case_002_False_Capability_Signal.md)
   - [Misattribution of Failure](evidence/demonstrations/OSI_Evidence_Case_003_Misattribution_of_Failure.md)
3. Continue to the [Live Sandbox Graph Tour](evidence/visualizations/LIVE_SANDBOX_GRAPH_TOUR.md) for the controlled graph-projection evidence.

For the complete collection, visit [Evidence and Demonstrations](evidence/).
For what these demonstrations do and do not authorize, read [Project Status](PROJECT_STATUS.md).
