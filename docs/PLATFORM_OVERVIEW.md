# OSI Platform Overview

## Purpose

Organizational Systems Intelligence (OSI) is a human-centered research and engineering platform for understanding how people, capabilities, relationships, organizational conditions, and state changes interact.

PIA provides the participant-level evidence foundation. OSI uses assured participant and organizational data to construct explainable system-level intelligence.

## Platform sequence

```text
Participant Package
↓
CSV Assurance Engine
↓
Assurance Report
↓
Graph Import
↓
Graph Assurance
↓
Analytics
↓
Organizational Health Intelligence
↓
PIA-informed longitudinal reasoning
```

## Participant package

The participant package preserves source-grounded information about a participant, their experience, evidence, and mapped capabilities. Source facts remain distinguishable from interpretation.

## CSV Assurance

The CSV Assurance Engine evaluates the canonical package across Contract, Validation, Congruence, Regression, Performance, Ethics, Epistemic Integrity, and Audit dimensions. Its canonical output is an Assurance Report.

## Graph import

Only assured packages should proceed to graph import. The import layer transforms accepted participant packages into the canonical Neo4j organizational model while preserving provenance and audit references.

## Graph assurance

Graph Assurance will verify structural integrity, relationship validity, provenance continuity, and compatibility with the platform contracts.

## Analytics

Analytics will operate on assured graph structures rather than raw CSV records. Planned capabilities include workforce flow, capability analysis, trust indicators, network analysis, organizational metabolism, and state-transition analysis.

## Organizational intelligence

Organizational intelligence should remain evidence-grounded, reproducible, explainable, and reviewable by human decision makers. OSI is a diagnostic instrument for system understanding and repair, not a mechanism for surveillance or automated judgment.

## Architectural dependency

Each layer depends upon the integrity of the layer below it. No downstream capability should bypass assurance, provenance, traceability, ethics, or participant consent.
