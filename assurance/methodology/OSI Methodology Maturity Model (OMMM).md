# OSI Methodology Maturity Model (OMMM)

## Purpose

The OSI Methodology Maturity Model provides an objective framework for evaluating the development of the OSI analytical methodology.

Unlike software version numbers, maturity levels describe confidence in the methodology itself.

A methodology advances only by satisfying the criteria of the next level.

---

# Level 0 — Concept

## Objective

Define the problem and core ideas.

### Characteristics

- Initial concepts
- Brainstorming
- Exploratory ontology
- Research notes

### Exit Criteria

- Core problem defined
- Initial terminology established

---

# Level 1 — Formalized

## Objective

Create a documented analytical framework.

### Characteristics

- Architecture documentation
- Ontology
- Design principles
- Standards
- ADRs
- Repository organization

### Exit Criteria

- Methodology documented
- Terminology standardized
- Architecture reproducible

---

# Level 2 — Operational

## Objective

Demonstrate the methodology using real data.

### Characteristics

- Canonical import model
- Repeatable imports
- Working graph database
- Analysis queries
- Standard reports
- Validation scripts

### Exit Criteria

- Multiple datasets imported
- Repeatable graph construction
- Stable ontology

---

# Level 3 — Assured

## Objective

Validate analytical integrity.

### Characteristics

- Evidence Assurance Gate (EAG)
- Graph Integrity Gate (GIG)
- Assessment Assurance Gate (AAG)
- Confidence model
- Audit artifacts
- Traceability
- Analyst review workflow

### Exit Criteria

- Every analytical product accompanied by assurance artifacts
- Conclusions demonstrably supported
- Methodology resistant to unsupported inference

---

# Level 4 — Generalized

## Objective

Demonstrate applicability across organizations.

### Characteristics

- Multiple organizations
- Diverse industries
- Multiple analysts
- Heterogeneous datasets

### Exit Criteria

- Minimal methodology changes required across domains

---

# Level 5 — Predictive

## Objective

Demonstrate predictive value.

### Characteristics

- Forecasts
- Longitudinal studies
- Outcome measurement
- Prediction accuracy

### Exit Criteria

- Measurable predictive success

---

# Level 6 — Scientific

## Objective

Demonstrate independent reproducibility.

### Characteristics

- Peer review
- Independent implementations
- Published methodology
- Replicated findings

### Exit Criteria

- Independent researchers reproduce results without the original authors
