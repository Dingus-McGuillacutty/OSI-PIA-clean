# OSI / PIA Project Status

**Status:** Research and development
**Last updated:** 2026-08-01

## Projects

### OSI

Organizational Systems Intelligence provides evidence-based organizational
reasoning.

### PIA

Personal Intelligence Architecture provides evidence-based personal
capability reasoning while preserving participant agency and privacy.

## Current milestone

The repository now has:

- explicit shared, OSI, PIA, implementation, and test namespaces;
- independent OSI and PIA reference-graph specifications;
- governed ontology, graph, connector, contract, software, and decision
  registries;
- a Governance Model at Congruence with completed Validation evidence;
- automated assurance and repository-governance validation;
- a local-only boundary for participant datasets;
- a validated Phase 2A synthetic intake sandbox;
- a working Phase 2B protected Windows-local participant-intake candidate
  with encryption, authentication, malware inspection, withdrawal, deletion,
  retention, recovery, and tamper validation;
- bounded protected evidence extraction, participant-controlled review,
  authenticated session continuation, and permanent retirement of deleted
  session identifiers; and
- the first participant-free Phase 3 credential-definition catalog and
  resolver, with public-source provenance and independent-review boundaries.
- a participant-free OSI organizational-evidence package and assurance
  validator covering organization, provenance, evidence, bounded observations,
  confidence, negative boundaries, and accountable review;
- a synthetic-only OSI sandbox projection path restricted to the local
  `OSI-Sandbox` database; and
- two explicit OSI synthetic imports followed by read-only validation proving
  one organization, source, evidence, observation, relationship, and expected
  path with idempotent structure.

The current formal checkpoints are
[OSI Synthetic Sandbox Projection Assurance](docs/history/MILESTONE_2026-08-01_OSI_SYNTHETIC_SANDBOX_PROJECTION_ASSURANCE.md),
[OSI Synthetic Organizational-Evidence Assurance](docs/history/MILESTONE_2026-08-01_OSI_SYNTHETIC_ORGANIZATIONAL_EVIDENCE_ASSURANCE.md),
and the preceding
[PIA Synthetic Sandbox Projection Assurance](docs/history/MILESTONE_2026-07-30_PIA_SYNTHETIC_SANDBOX_PROJECTION_ASSURANCE.md).
These build on the protected PIA intake, evidence-review, credential, and
mapping milestones.
The implementation is coherent and testable but remains
`working/proposed`. Real-participant use still requires completion of the
controlled-pilot gate. Real organizational use, OSI diagnostics, analytics,
and imports into `osi-reference` are not authorized.

## Data boundary

The repository contains contracts, schemas, generic import mechanisms,
synthetic tests, and methodological examples. Participant source material,
normalized records, derived participant evidence, and participant-specific
imports are not release artifacts and must be supplied from private local
sources when a consented test requires them.

Development findings based on participant material belong in the restricted
development archive, not in the sanitized release lineage.
